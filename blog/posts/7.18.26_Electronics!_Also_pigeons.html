Recently I've started learning about electronics! I really want to be able to confidently make circuits and use microcontrollers. I want to build up good fundamentals without using microcontrollers first, then give microcontrollers a try. I feel like if I start by using microcontrollers they might become too much of a crutch.

I started by watching random youtube videos that explain electronics concepts. Eventually I stumbled upon vocademy.net , which is where I'm learning from now. It's much nicer to have a guided instruction that doesn't skip over core fundamentals then it is to try and piece things together from a bunch of random videos, so I'm thankful for that site existing.
